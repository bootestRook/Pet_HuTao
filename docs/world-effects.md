# 每局随机效果

每局正式开战时，由服务端从以下四种效果中等概率抽取一种，各为 **25%**。玩家和观众共享同一结果；刷新、重连和中途观战都不会重新抽取，再战时重新抽取。

周期从本局战斗计时零点开始。神之天平的两秒暂停不计入战斗时间，五分钟上限仍按实际战斗计时判断；暂停期间小球、道具、飞扑、骰子、持续伤害、无敌和其他技能倒计时全部冻结。

| 效果 | 首次触发 / 周期 | 规则与画面反馈 |
| --- | --- | --- |
| 神之天平 | 35秒 / 每35秒 | 冻结战场2秒，金色连线在双方间流动，天平从倾斜逐渐归正；暂停结束时均分存活小球的当前生命。 |
| 天降厄运 | 30秒 / 每30秒 | 服务端随机生成5个落点，预警0.8秒后砸下杂物；每个落点半径26，命中造成3点环境伤害，并眩晕3秒。显示落点、下落、冲击和跟随小球的眩晕星星。 |
| 青青草原 | 60秒 / 每60秒 | 所有存活小球恢复20点生命，最多恢复至自身上限；场边草叶、绿色扩散光圈及跟随目标的回血光效和飘字反馈。 |
| 幸运大奖 | 50秒 / 每50秒，领取后停止 | 场内随机出现一个金色奖杯，存在5秒，首次接触它的小球获得下表随机奖励之一；三种奖励等概率，各为1/3。未被领取则到期消失，下一周期再次出现。 |

| 大奖奖励 | 数值与期限 |
| --- | --- |
| 无敌 | 20秒内免疫所有伤害，包含碰撞、角色、道具、自损、分期及环境伤害；不免疫控制。金色护罩随球移动。 |
| 回血 | 恢复自身最大生命的50%，不超过生命上限，统计只记录实际恢复量。 |
| 增伤 | 小球造成的所有对外伤害+5，持续至本局结束，含碰撞、巴掌、汲取、道具、退货与反伤。自损及环境伤害不增加；分期按已增加后的总额分摊，后续扣款不再次+5。显示随球增伤标记。 |

## 结算边界

- 天平按当前生命数值均分，允许半点生命。不同最大生命时，先满足较低的生命上限，其余生命分给另一球，保留总生命。均分扣血属于生命转移，不经过无敌、保命、分期或退货判定；增加的生命计入实际治疗，转出的生命不计为攻击伤害。它不直接触发碰撞回血或忆往昔。
- 同一落点可以命中双方；多个落点重叠时，每次命中独立造成3点伤害，眩晕刷新至最后一次命中后3秒。无敌可挡伤害，仍会被眩晕。环境伤害不计入任一玩家的伤害统计，不生成欠款或退货码；仍通过统一的无敌、保命及后悔药结算入口。
- 眩晕期间位置固定，被撞时由另一球反弹，眩晕球不被推走。不能打出碰撞伤害，仍可受到碰撞伤害，定时技能和道具伤害继续结算。正在进行的飞扑被打断，眩晕结束后才可再次发起飞扑；马桶传送、后悔药位移与充气等待恢复移动。
- 大奖使用球体半径加奖杯半径18判定触碰，满血也能领取。服务器同一步检测到双方触碰时优先距离更近者，距离相同则服务端等概率选一位，避免座位优先。领取后只发一次奖励并移除奖杯，整局不再生成。
- 正常模拟步依次结算碰撞、角色技能、道具，再结算战场效果；前序已致死则立即结束。同次落物先捕获全部命中，再统一判断胜负，允许双方同刻倒下。治疗不复活；结束后清除预警、落物、奖杯、控制和增益，取消未完成结算。
- 五分钟终点恰好到期的青青草原即时治疗先结算，再比较剩余生命比例；终点不再发起需要继续等待的落物、奖杯或天平暂停。
- 落点、奖杯、奖励和血量由服务端决定并随快照同步。客户端只插值和绘制，角色状态与回血飘字持续跟随每帧插值位置；定点落物和奖杯保留在服务端坐标。减少动态模式保留预警、结果与状态文字，去除装饰性旋转、跳动和移动粒子。
